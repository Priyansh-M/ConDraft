# ConDraft

India-only drafting aid. Not a law firm. Not legal advice.

The finished model is an **11-month residential leave and licence**. Other contract types are stubs. Citations come from a curated India Code list, not from an AI.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. You must tick the disclaimer to enter, and again before a PDF download.

## Stamp duty

The app never calculates or waives stamp duty. You pick a State, open that State’s official registration / e-stamp site, read the current schedule, and type the amount yourself (or leave it blank).
